# Esporte Clube Itapetininga

Este repositório guarda a versão original do site em HTML, CSS e JavaScript e a migração para React Native com Expo em [`mobile/`](mobile/README.md). A versão original foi registrada no primeiro commit para permitir comparação e recuperação.

Para trabalhar no aplicativo migrado:

```powershell
cd mobile
npm ci
npx expo start
```

No terminal do Expo, use `w` para abrir a versão web ou o aplicativo Expo Go para Android/iOS. Para gerar as páginas web estáticas, execute `npm run build:web`.

O acesso administrativo é um **protótipo acadêmico local**. Não use as credenciais demonstrativas com dados reais.
